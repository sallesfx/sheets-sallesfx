Guia Rápido de Navegação e Manipulação de Arquivos • sallesfx.com.br

📁 1. Navegar e Localizar
pwd Exibe o caminho absoluto do diretório atual.
cd ~/pasta Navega para a pasta no diretório pessoal.
cd - Volta ao último diretório acessado.
cd .. Sobe um nível para o diretório pai.
🔍 2. Listar Conteúdo
ls -lh Lista detalhes com tamanhos legíveis (KB, MB).
ls -la Exibe todos os arquivos, incluindo ocultos (.).
tree -L 2 Exibe estrutura de pastas até nível 2.
🛠️ 3. Criar e Mover
mkdir -p a/b/c Cria pastas e subpastas aninhadas.
cp -r orig/ dest/ Copia diretórios e conteúdos recursivamente.
mv arq.txt ~/docs/ Move ou renomeia arquivos e pastas.
⚡ 4. Remover com Segurança
rm arquivo.txt Remove um arquivo comum permanentemente.
rm -ri pasta/ Remove diretório pedindo confirmação por item.
rm -rf pasta/ Força remoção sem confirmação (Cuidado!).
